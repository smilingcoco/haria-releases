# Haria · versiones

Aquí se publican las versiones de **Haria**, un espacio tranquilo para escribir y leer sin perder el hilo.

**Descargar:** abre la [última versión](https://github.com/smilingcoco/haria-releases/releases/latest) y baja el archivo `.dmg`. Sirve para cualquier Mac (Apple Silicon e Intel) con macOS 11 o posterior.

**Primera vez:** arrastra Haria a Aplicaciones. Como aún no está firmada por Apple, la primera vez ábrela con clic derecho › Abrir. Después se actualiza sola: cuando haya una versión nueva, aparecerá un punto en «···».

---

*Haria* significa «hilo» en euskera. *Ez dadila haria eten.*
